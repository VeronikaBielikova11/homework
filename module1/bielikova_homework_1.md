Завдання 1. Дослідження мережі
1. Інтерфейс: en0.
2. Тип підключення: Wi-Fi (бездротове підключення).
3. MAC-адреса: be:db:25:6c:f9:c1 — канальний рівень моделі OSI (2-й рівень).
4. IP-адреса: 192.168.211.17 — мережевий рівень моделі OSI (3-й рівень).
5. Маска підмережі: 255.255.254.0 (/23) — мережевий рівень моделі OSI (3-й рівень).
6. Gateway: 192.168.210.1 — шлюз за замовчуванням для зв’язку з іншими мережами.
7. Broadcast: 192.168.211.255 — адреса для надсилання пакетів усім пристроям підмережі.
8. Hosts: 510 доступних адрес для пристроїв у підмережі — від 192.168.210.1 до 192.168.211.254.

Пояснення:
Мережевий інтерфейс en0 використовується для підключення до Wi-Fi. MAC-адреса ідентифікує мережевий інтерфейс на канальному рівні моделі OSI. IP-адреса, маска підмережі та broadcast-адреса належать до мережевого рівня. Маска /23 визначає мережу 192.168.210.0, яка містить 512 адрес, з яких 510 доступні для пристроїв. Шлюз 192.168.210.1 забезпечує передавання даних до інших мереж. IP-адресу та мережеві параметри пристрій отримав через DHCP.



Завдання 2. Дослідження маршрутизації
1. Маршрут за замовчуванням: default.
2. Gateway: 192.168.210.1.
3. Мережевий інтерфейс: en0.
4. Протокол отримання IP-адреси: DHCP.

Пояснення:
Таблиця маршрутизації визначає шлях передавання мережевих пакетів. Маршрут за замовчуванням використовується, якщо для адреси призначення немає конкретнішого маршруту. У цьому випадку пакети до інших IPv4-мереж передаються через шлюз 192.168.210.1 за допомогою інтерфейсу en0. Протокол DHCP автоматично надає пристрою IP-адресу, маску підмережі та адресу шлюзу. DHCP не є протоколом маршрутизації — він відповідає за автоматичне налаштування мережевого підключення.



Завдання 3. Знаходження публічної IP-адреси
1. Локальна IP-адреса: 192.168.211.17.
2. Публічна IP-адреса: 93.170.0.1.
3. Чи однакові адреси? Ні, вони відрізняються.

Пояснення:
Локальна IP-адреса 192.168.211.17 використовується для ідентифікації пристрою всередині локальної мережі. Вона належить до приватного діапазону IPv4-адрес і не використовується для безпосередньої маршрутизації в публічному Інтернеті.
Публічна IP-адреса 93.170.0.1 визначається зовнішнім сервісом ifconfig.io і показує адресу, з якої сервіс бачить з’єднання. Домашній роутер зі шлюзом 192.168.210.1 забезпечує зв’язок між локальною мережею та Інтернетом. Для цього зазвичай використовується NAT (Network Address Translation), який дає змогу пристроям із приватними IP-адресами виходити в Інтернет через публічну IP-адресу.


Зрозуміла, що навіть якщо пристрій має власну локальну IP-адресу, в інтернет він може виходити через спільну публічну IP-адресу роутера. Також стало зрозуміліше, як пристрої знаходять шлях до інших мереж за допомогою шлюзу за замовчуванням.
